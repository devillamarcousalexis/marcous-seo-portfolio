# Marcous Alexis De Villa — Technical SEO Portfolio

A recruiter-focused personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

Requirements: Node.js 22 or newer and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production check

```bash
npm run build
npm start
```

## Customize the content

- Main page and case studies: `app/page.tsx`
- Page metadata: `app/layout.tsx`
- Styling: `app/globals.css`
- Favicon: `public/favicon.svg`

## Deploy

Push this project to GitHub, import the repository into Vercel, and accept the detected Next.js settings. No environment variables or database are required for this version.
